#  Calculator Application (Python)

##  Description
This is a simple command-line based Calculator application developed using Python.  
It performs various arithmetic operations based on user input.

##  Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Modulus (%)
- Exponentiation (**)

##  Technologies Used
- Python  

##  How to Run
1. Clone the repository  
2. Open the project in VS Code or any IDE  
3. Run the Python file:

```bash
python calculator.py
